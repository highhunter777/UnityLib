# 克隆后自备清单

> 用途：本仓库只保留**自研框架代码、预制品与文档**（详见 `.gitignore` 两组忽略段）。
> 克隆到新机器后，以下内容需**自备**才能完整打开/运行工程；如需把某一项纳入版本管理，用 `git add -f <路径>` 显式添加。

## 1. 必须自备（否则工程打不开或编译不过）

| # | 路径 | 内容 | 从哪来 |
| --- | --- | --- | --- |
| 1 | `ProjectSettings/` | Unity 工程设置（PlayerSettings 含 `HIDE_REFLECTION` 宏、URP/质量/输入/标签等 26 个 asset + `ProjectVersion.txt`） | 本机工程自带（首次需从原机拷贝或重建） |
| 2 | `Assets/Plugins/Sirenix/` | **Odin Inspector 4.0.2.3**（付费授权，不可再分发；`LiteGame.Editor` 的标记工具/编排器依赖它） | Asset Store（按席位授权） |
| 3 | `Packages/MCPForUnity/` | 编辑器自动化桥（我们的 MCP 工具链；不影响运行时） | 本地包目录（或团队共享） |
| 4 | `Packages/manifest.json` / `packages-lock.json` | ❌ **不入库，本机自备**（d122abd 起移出追踪）——依赖声明：HybridCLR=gitee git URL；YooAsset/Luban/VContainer=本机 `file:` 路径引用；DOTween=`Assets/Plugins/Demigiant`（已忽略）；TMP/Cinemachine 等走 UPM registry | 本机工程自带；新机器需按原机 manifest 逐项重建依赖声明 |

| # | 路径 | 内容 | 备注 |

## 3. 美术与素材资源（仅 demo 用，不入库）

| # | 路径 | 内容 |
| --- | --- | --- |
| 7 | `Assets/Art` / `Map` / `Animation` / `FX` / `Model` / `Sound` | UI 图标与图集、工业地图、枪械动画（Erika Archer 31 个）、粒子特效、低模武器与角色、Kenney 音效 |

## 5. 恢复动作速查

```bash
# 把某项显式纳入版本管理（例如团队决定把 ProjectSettings 也入库）
git add -f ProjectSettings/

# 反向：撤销跟踪但保留本地文件
git rm -r --cached ProjectSettings/
```
