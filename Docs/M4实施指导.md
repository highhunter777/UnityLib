## 1. 前置决策（开工前定案）

### 1a. 渲染栈（定案 2026-09-13）
UGUI + TextMeshPro——manifest 既定依赖，无悬念。DOTween 只做转场/表现（M5 红线提前生效：判定不碰 DOTween）。

### 1b. 绑定双路径范围（定案）
路径 A（标记即数据，主路径）**全量交付**：`BindNode` 补显式 `BindName` 字段 + `BindIndexBuilder` 运行期读标记建索引。路径 B 交 `UIBindBase` 双模式索引基类 + 一个最小示例走通 Designer 字段登记即验收；BindCodeGen 生成器侧只做"生成路径与 UI 程序集对齐"的小改（ScriptsFolder 默认值指向 LiteGame），**不扩功能**。

### 1c. SafeArea（定案）
`ISafeAreaStrategy` 接口 + 默认实现（SafeAreaReceiver 驱动 CanvasScaler 偏移）随 UI 壳交付；`Screen.safeArea` 为唯一事实源，横竖屏/分屏自动跟随；DevHUD 豁免（仅电脑测试，已定）。

### 1d. 薄壳三件全进 M4（定案，手册 §六步骤 6）
实体壳（池化 + 生命周期容器 + 加载竞态表）与声音壳（组 + 代理轮转）按手册最小形态交付，**均不转发 Lua**。

### 1e. 时序执行三决策（M4 开工第一步复核定案，本规划建议默认）
①驱动源 = 双时钟分轨：逻辑时序挂 `IWorldClock`、表现时序挂 `IUIClock`（Timescale=0 冻结语义由时钟层给，执行器不自读 Time）；②序列等待模型 = **回调注册**，不用协程（协程对象生命周期与暂停/恢复语义冲突）；③调度器到期判定 = 逻辑帧累积。定死并记录后 M5 直接消费。

### 1f. 资产与收集（定案）
新增收集组 `LiteGameUI`（CollectPath: `Assets/UI`，**PackSeparately**——单界面单包体支撑热更粒度），收集器 tag `ui`；`Assets/UI/UIMain.prefab` 建灰盒骨架（全屏页 + 一个 Button + TMPro 文本 + BindRoot/BindNode 标记 + SafeAreaReceiver），**含占位美术**（2026-09-13 定案）：UGUI 内置 Sprite + 纯色块 + 默认字体，不引入外部素材；tbuiform 行 prefab 列 `UI/UIMain.prefab` 与收集后 location 对齐。

### 1g. Bridge.ui 门面 API（定案最小集——§4.7"M4 定 UI 壳 API 前定死"的落点）
`Show(id)` / `Close(id)` / `IsOpen(id)`——id 为 TbUIForm 行主键；**Lua 不触碰 GameObject / prefab 名字**（受控 API 面 §4.6）。`Bridge.content` 保持骨架。

### 1h. 七态映射（定案）
C# `UIFormState`：Loading→OnInit→Active⇄Covered/Paused→Closing→Recycled（GF UIManager 同款）；`IUIFormLogic` 七回调 = OnInit / OnShow / OnUpdate / OnPause / OnCover / OnReveal / OnHide（手册 §六步骤 3 回调名表为准）。

## 2. C# 侧步骤

### 2.0 契约先行
- `IUIFormLogic`（七回调接口——LuaBehaviourAdapter 与 C# 界面逻辑同面）+ `UIFormInfo`（TbUIForm 行投影：id/LuaPath/Prefab/Layer/FullScreen，**壳不碰 Luban 类型**，投影在装配层做）
- 落位：`LiteGame/Scripts/Runtime/Shell/UI/`（与 SceneService 同层——薄壳不进框架 Core，设计方案 §1.3）

### 2.1 UI 壳机制（手册步骤 1）
- `UIStack`（开/关/暂停恢复）+ `UILayerGroup`（层级组 + Depth 分配，**组级批量暂停**——FullScreen 界面激活时低层级组批量 Pause）+ 实例化管线（`AssetService.LoadAssetAsync` → 挂壳）+ 七态机
- 全部壳件实现 ITickable/IModuleStats（HUD 即见）

### 2.2 策略三件（手册步骤 2）
- `ILayerStrategy` / `ITransitionStrategy` / `IPopInterceptor` 接口 + 默认实现（壳内自带）；壳构造注入——**策略不写死进壳**；Lua 经 Strategies 注册表替换的 fill 位预留（M3 填充链已通，M4 不必真用 Lua 策略）
- 转场默认实现的动效规格与性能纪律见《动效设计方案》（2026-09-13）：SetLink 防泄漏 / Canvas 拆分 / UIClock 驱动

### 2.3 LuaBehaviourAdapter + 门面（手册步骤 3）
- Adapter：持 LuaTable，把 `IUIFormLogic` 七回调翻译成 `self:OnInit/...`；逐回调经 SafeCall 防护（单回调抛 = 该界面降级，不炸壳——错误语义同事件桥）
- `Bridge.ui` 换真实语义：`Show/Close/IsOpen(id)`（§1g）
- **DevReload 编排增一步**：env 重建后已打开界面持旧 LuaTable 全失效——定案**重载后全部关闭**（最简、无隐藏状态）；编排顺序并入 M3 §2.7 钉死清单

### 2.4 绑定面（手册步骤 4）
- `BindNode` 增 `BindName` 字段 + Inspector 支持
- `BindIndexBuilder`：实例化后扫 BindRoot/BindNode 建 name→control 索引（一次构建、缓存）
- `UIBindBase`：双模式索引（运行期读标记 / 读 Designer 字段登记——基类同吃两路）
- 受控 API：`GetControl(name)` / `OnButton(name, fn)`（**返回注销委托**，内部 SafeCall）/ TMPro 文本 / 显隐 / 交互开关 / 坐标——**不裸抛 GameObject**（§4.6）

### 2.5 通用组件口子（手册步骤 5）
- 虚拟列表**数据源接口**（Lua 侧实现，经适配器）+ 最小渲染验证件（不做完整虚拟化）
- 红点规则注册口、转场策略注入位（ITransitionStrategy 已是）

### 2.6 SafeArea 接收器（刘海屏红线兑现）
- `SafeAreaReceiver` + `ISafeAreaStrategy` 默认实现；UIMain.prefab 挂上，Device Simulator 验四角

### 2.7 实体壳（手册步骤 6）
- 池化 GameObject + 生命周期容器 + **加载竞态表**（异步加载中收到 Hide → 记入集合，加载完成立即回收——GF EntitiesToReleaseOnLoad 同款）；不转发 Lua

### 2.8 声音壳（手册步骤 6）
- 组 + 代理模型：一组 N 个代理轮转（并发通道，同组音效可叠加）、组音量/静音、同优先级不被替换；播放入口收口（业务禁裸 AudioSource）

### 2.9 时序执行（手册步骤 7，M5 前就绪）
- 调度器：动作点/定时注册、到期触发、可取消；序列执行器：有序步骤表推进（剧情与技能共用）
- 三决策按 §1e 建议默认复核定死；**业务禁止裸调 UniTask 时间原语**（M5 红线提前生效）

## 4. 测试与自测策略

xUnit 双轨只覆盖可剥离纯逻辑（七态机转换表 / Depth 分配 / 声音代理轮转算法——收进无引擎小类）；**权威断言 = Play 冒烟**（手册自测五条 + SafeArea）：

1. Lua UIMain 全生命周期 Show/Pause/Hide——七回调逐个日志可见
2. 按钮响应一次；注销后不再响应
3. 弹窗盖住 UIMain → OnCover 触发；移开 → OnReveal 触发
4. 出栈拦截策略挡一次返回
5. 虚拟列表数据源驱动一次刷新
6. 同组两音效叠加播放且组静音生效
7. Device Simulator 模拟刘海——四角不入异形区
8. DevReload 回归：重载后 UI 全关，再 Show 正常（§2.3）
