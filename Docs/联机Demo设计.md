## 2. Sim 内容清单（住 Sim 的判定）

移动/朝向（clamp 校验）、射击与命中（回溯）、伤害/死亡/复活、**技能**（前摇计时/冷却/持续时间/判定窗/位移/护盾值）、KDA 与比分、结算触发。

**客户端预测边界**（§5.3 表）：移动/朝向预测；**开火不预测**；**技能不预测**（离散事件，猜错代价大——沿用 §5.3 判据；技能表现可在确认后立即播放）。

## 3. 表现层清单（LiteSim.View）

槽位→GameObject 镜像、远端插值、和解重对齐（本地局部位移误差衰减）、**相机服务（§3.1）**、血条/头顶、命中反馈、**技能表现**（前摇提示/判定范围指示/特效/音效——表现时序走 IGameClock，不跨语言逐帧回调，§4.3 热路径纪律）。

### 3.1 相机服务（2026-09-14 定案：**要规划，属表现层服务，不进框架**）

**定位判据**（按 §8.1 四模式）：相机**无玩法状态**（不参与判定、不改 Sim）→ 是**服务**；但它有**跨模式的一致性规则**（俯视角/观战/回放/调试）+ 联机特有问题（和解期行为、震屏防重播、时钟轨）→ 值得**显式规划成一个表现层服务**，而不是散在若干 MonoBehaviour 里。

| 项 | 设计 |
| --- | --- |
| 归属 | **`LiteSim.View` 内的服务**（`ICameraService`），由 View 装配；**不进 LiteFramework**（框架只放契约，不碰相机） |
| 实现 | **Cinemachine**（工程已有 2.10.7）承接跟随/阻尼/Impulse；自研部分只有"模式切换、目标切换过渡、和解期策略"薄层 |
| **跟谁（联机核心）** | **本地玩家跟预测位置**（0 延迟手感）；观战/回放跟插值位置；目标切换有短过渡（不可瞬切） |
| **和解期行为** | 相机跟随**已衰减后的表现位置**（§6.2 既有"本地不 snap、远端才 snap"）→ 天然平滑；仅当误差超阈值（复活/传送）才允许硬切 |
| **震屏** | Cinemachine **Impulse** + 由 **View 观察状态变化**触发（§520）+ `silenceUntilFrame` **防重播**（既有决议） |
| 时钟轨 | 挂 **IWorldClock**（世界表现：时停即冻结）；UI 用 Screen Space Overlay（不依赖相机，简化 UI 与相机耦合） |
| **模式档位** | 俯角/距离/FOV/边界夹取由**模式策略包**提供（§14 `INetGameStrategy` 的 ViewRule/参数面）→ 相机不认识"模式"，只吃参数 |
| 边界 | 相机**不读 Sim 内部结构**（只吃表现层已解析的位置/朝向）；**不参与判定**（震屏/推拉都不能改任何逻辑） |
| 验收 | ①本地移动无延迟感、远端平滑 ②和解时相机不抖（与"本地修正不微抖"同条验收）③回滚重放期不重播震屏 ④时停/变速下相机行为正确 ⑤俯视角 ↔ 观战切换有过渡 |

## 5. 技能数据链路（与时间轴编辑器接口）

> **编辑器定案（2026-09-14 二次修订）**：**直接采用 Unity Timeline（内置 1.7.6）做编排编辑，不自研画布**（《编辑器设计规划》§3）——自研仅三件：自定义轨（判定/表现语义）、导出器（TimelineAsset → 表）、导出校验。**骨骼与属性动画走 Timeline 的 Animation Track（AnimationClip/Animator）**，不进表。

```
Unity Timeline（TimelineAsset，时序真相；程序/TA 编辑）
  ＋ tb_action_num（数值真相：冷却/前摇/伤害/半径；策划编辑，可 diff、可热更）
   ↓ [一键导出]（含保存自动触发）→ CSV：tb_timeline.tracks（时序列，产物）
   ↓ gen.bat → binary
   → Sim 读判定轨 + 数值表；表现层读表现轨（序列执行器 + UiFx）
```

- **秒→帧硬规则**：导出时 `帧 = round(秒 × 60)` 且 `|秒×60 − 帧| < 1e-4`，否则导出被拒（防判定帧两端不一致）
- 判定与表现**同一条时间轴对齐**（不会"判定 12 帧、表现 18 帧"错位）
- **联机技能表现不直接跑 PlayableDirector**（走序列执行器，避开与"快照驱动 + 和解重对齐 + silenceUntilFrame"的摩擦）；非对局演出可直接跑 Timeline
- 一键导出 + 非对局态热生效、对局中禁止重载（《编辑器设计规划》§3.5）

## 7. 验收（demo 完成判定）

1. 8 人房完整一局（含三个技能的使用、冷却、命中判定）跑通不崩
2. 和解率达标（Ops 指标在阈值内，§4.5 关键机制 4）
3. 断线重连成功（权威快照恢复路径）
4. **技能在 Sim 内生效**：前摇/冷却/判定与服务器一致，表现与 CD UI 与 Sim 状态一致（不出现"表现放了、判定没放"）
5. AOI 用例：远距离实体不出现在快照中
6. 零 `CS.` 裸引用；UI 全部走控件库 prefab 模板 + Lua 逻辑表
7. 双平台可玩：PC 键鼠 + 手机触屏（机型适配遗留项的验收点）
