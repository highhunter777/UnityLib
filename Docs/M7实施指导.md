| 11 | SimRng | **Xorshift64\***（`ulong` 状态）；`NextUInt32 / NextFloat01 / NextRange(int,float)`；随机状态进快照（M8 接入） | §2.2 |

### 2.1 `SimMath`（~80 行）

**API 契约**：
```csharp
public static class SimMath
{
    public const float Dt = 1f / 60f;               // 逻辑帧步长（与 SimConfig 同源）
    public const float Tolerance = 1e-6f;

    public static bool NearlyEqual(float a, float b);          // |a-b| <= Tolerance（绝对）
    public static float Clamp(float v, float min, float max);
    public static float Clamp01(float v);
    public static float Lerp(float a, float b, float t);       // 禁 Mathf（本程序集无 UnityEngine）
    public static float Abs / Min / Max (float);
    public static int   Abs(int);
}
```
**要点**：文件头注释写死**单位约定（米/秒、弧度）与 IEEE 边界纪律**（禁超越函数、禁 FMA 写法、禁精度依赖比较）——§11-4 验收项。
**用例**：`NearlyEqual` 边界（恰等于容差/超出）、`Clamp01` 极端值、`Lerp` 端点。

### 2.2 `SimTrig` + 生成器（~150 + ~120 行）

**生成器（Editor）**：
- 菜单 `LiteSim/生成 SimTrig 查表` → 产出 `SimTrigTables.cs`（**入库**）
- 表内容：`SinTable[4096]`（覆盖 `[0, π/2]`，用 `Math.Sin` 填 —— **仅生成期允许**）；表头注释标注"生成物，勿手改"+ 生成参数
- 幂等：重复执行产出逐字节一致（排序/格式化固定）

**运行期 `SimTrig`（查表 + 归约 + 插值）**：
```csharp
public static class SimTrig
{
    public const int TableSize = 4096;
    public static float Sin(float radians);      // 象限归约 → 查表 → 线性插值
    public static float Cos(float radians);      // Sin(radians + π/2)
    public static float Atan2(float y, float x); // octant 归约 → 查表 → 插值
    public static float Tan(float radians);      // Sin/Cos（分母容差保护）
}
```
**要点**：
- 归约只用**加减法与整数运算**（IEEE 基本运算 ✓）；插值 `a + (b-a)*t` ✓
- **边界保护**：`NaN/Inf` 输入 → 返回 0 并 Debug 断言（Debug 三宏）
- 不在运行期出现任何 `Math.`/`MathF.` 超越函数（lint 验收项）

**用例**：①精度：与 `Math.Sin` 逐点比对（采样 10k 点，**|误差| ≤ 1e-5**）②象限边界（0/π/2/π/3π/2/2π、负角、大角 1e5 rad）③`Atan2` 四象限 + 轴上（含 0,0）④`Tan` 接近 π/2 的行为 ⑤**重现性**：同一输入序列两次调用结果逐位一致

### 2.3 `SimVector3`（~180 行）

**API 契约**：`struct SimVector3 { float X, Y, Z; }` + 运算符（`+ - * float /`）+ `Dot/Cross/Length/LengthSquared/Normalized`（除以零保护）+ `Distance` + `ToString`
**要点**：`Length` 用 `(float)Math.Sqrt`？**→ 用 `SimMath` 内的 `Sqrt` 包装（`MathF.Sqrt` 或 `(float)Math.Sqrt` 均可，sqrt 是 IEEE 基本运算 ✓）**；`Normalized` 在长度 < 容差时返回零向量（禁 NaN 扩散）
**用例**：运算符一致性、`Dot/Cross` 已知值、`Normalized` 零向量、`Length` 与勾股精度、结构体**无装箱**（对比 `object` 装箱的分配用例）

### 2.4 `SimRng`（~80 行）

```csharp
public struct SimRng
{
    public ulong State;                                  // 进快照（M8）
    public SimRng(ulong seed);
    public uint  NextUInt32();
    public float NextFloat01();                          // (NextUInt32() >> 8) * (1f/16777216f)
    public int   NextRange(int minInclusive, int maxExclusive);
    public float NextRange(float min, float max);
}
```
**要点**：仅整数/位运算 + **乘法换算**（无除法精度依赖）；`NextFloat01` 用 24 位尾数构造（不引入 `double`）；序列稳定 = "同种子同序列"用例
**用例**：固定种子前 8 个值**硬编码期望**（回归锚点）；均匀性粗检（仅 sanity，不做统计强断言）；`NextRange` 边界与分布无越界

### 2.5 纪律 lint 扫描器（~150 行）

菜单 `LiteSim/纪律扫描`：文本扫描目标目录（默认 `Assets/LiteSim/`，可配），规则集：

| # | 规则 | 形态 | 生效范围 |
| --- | --- | --- | --- |
| R1 | **禁超越函数**：`Math.Sin/Cos/Tan/Atan2/Exp/Log/Pow`、`MathF.*` 同名 | 源码扫描（排除 `SimTrigTables.cs` 与 `Editor/`） | **M7 起硬规则** |
| R2 | **禁 FMA 写法**：`MathF.FusedMultiplyAdd`、`System.Math.FusedMultiplyAdd` | 同上 | M7 起 |
| R3 | **禁 float 精度比较**：`==`/`!=` 两侧含 float 变量（白名单：`SimMath.NearlyEqual`、与常量 0 的明确比较需注释豁免） | 同上 | M7 起 |
| R4 | **禁确定性容器/遍历**：`Dictionary` 遍历（`foreach` over dict）、`System.Linq`、不稳定 `Sort` | 同上 | **M8 起**（先把规则写进扫描器，命中即报） |

**输出**：逐条 `文件:行:规则:代码`，退出码非零（供将来 CI）——**M7 的验收演示 = R1~R3 各造一个负例被抓住**。
**用例**：规则集自测（对样例文本断言命中/漏报；豁免注释生效）。

### 2.6 IEEE 边界用例集（~120 行，属测试项目）

- **基础运算逐位一致**：对一批确定输入（含负数、极小/极大、`+0/-0`、次正规数）在 .NET 侧算 `+ - * /` 与 `Sqrt` → 结果 `BitConverter.SingleToInt32Bits` **逐位**记录为**基线文件**（入库）
- **Unity 侧对账**：Play/编辑态用同一批输入跑同一套运算 → 与基线**逐位比较**（等价于 §9 验收②"加乘除/sqrt 在 .NET 与 Unity 下一致"）
- **运算链 checksum**：`SimVector3` 混合运算 10k 步 + `SimRng` 序列 → 汇总 `uint` checksum 与基线一致（等价于 §9 验收③）

> 说明：Unity 侧对账**不引入 Play 断言框架**（数值层无引擎依赖）；用一次性 Editor 菜单/脚本跑，结果与基线文件比对（脚本落 `LiteSim.Core.Editor`，产物入 `Tests/LiteSim.Core.Tests/Baselines/`）。

## 6. 决策记录（本轮定案）

| # | 决策 | 备注 |
| --- | --- | --- |
| ① | 表长 **4096 + 线性插值**（sin/cos 共用一张 + 象限归约；tan 不建表） | 精度/体积/生成时间平衡 |

## 7. 边界与风险

- **与显式拒绝清单一致**：不引入 ECS/fantasy 类依赖；`LiteSim.Core` 保持 `references: []`（§1 分层纪律）
- **不预做 M8 的事**：本里程碑**不建** `SimWorldState`/系统/checksum 全量（M8）、不建快照回滚（M9）、不 vendor kcp2k（M10）
- **风险：表长与精度**——若 4096 精度不达标，先加插值阶数（线性→二次）再考虑加表长；**不加表长优先**（体积/生成时间）
- **风险：Unity 侧对账脚本**依赖编辑器菜单（非 CI）——记为技术债：CI 具备条件时把对账搬进 `dotnet test` + IL2CPP 真机跑（§测试开发方案）
- **风险：无 git**——生成物与基线文件一旦覆盖不可恢复，生成器必须幂等、基线文件更新前先备份
